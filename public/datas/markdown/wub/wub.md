## 概述

Windows Update Blocker是一款简单实用的工具，只需一键即可**完全禁用**或**重新启用** Windows 更新及相关服务。它适合希望完全掌控 

Windows 更新的用户,可防止不必要的系统更改、运行变慢或强制重启。

## 功能特性

- ✅ **一键禁用/启用 Windows 更新**
- ✅ **防止 Windows 自动重新启用更新**
- ✅ **轻量级便携工具(无需安装)**
- ✅ **支持 Windows 10 和 Windows 11**

## 使用方法

### 禁用 Windows 更新

1. **以管理员身份运行 `Wub.exe`**
2. 选择 **"Disable Updates"(禁用更新)**
3. 点击 **"Apply Now"(立即应用)**
4. ✅ 完成!Windows 更新服务现已禁用。

### 重新启用 Windows 更新

1. 打开 **WUB**
2. 选择 **"Enable Updates"(启用更新)**
3. 点击 **"Apply Now"(立即应用)**
4. 🔄 Windows 更新已恢复。

## 高级设置

- 点击 **"Menu"(菜单) > Service List(服务列表)** 可查看受影响的 Windows 服务。
- 你可以修改 `Wub.ini` 文件进行更多配置。

## 重要提示

- 某些第三方应用程序或 Windows Defender 可能会尝试重新启用更新。
- Windows 功能更新可能会重置 WUB 的设置——如有需要请重新应用。
